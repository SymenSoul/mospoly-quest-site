# Концепция квеста «Код манула»

Тема: **Московский зоопарк: генетика и кодирование**.
Документ описывает идею квеста, его блоки и о чём будут задания. Реплики интерфейса — в [scenario.md](scenario.md),
условия заданий, ответы и оценка сложности — в [tasks.md](tasks.md).

## Идея

Ночь в лаборатории генетики Московского зоопарка. Утром должен пройти учёт новорождённого детёныша манула
(манул — символ зоопарка). Для программы сохранения редких видов у каждого детёныша должен быть ДНК-паспорт
с подтверждённым происхождением. Иначе его не внесут в племенную книгу вида.

Вечером система «Генобанк» дала сбой: часть записей перепуталась, часть повредилась. Генетик Вера уехала
на срочный выезд в другой зоопарк и на связи только через терминал лаборатории. Участник — стажёр
на ночной смене. Он шаг за шагом восстанавливает данные: открывает лабораторию, читает ДНК, выясняет,
кто отец детёныша, и собирает его ДНК-паспорт.

Квест связывает две темы:
- **кодирование информации** — двоичный код, коды и таблицы, алгоритм на Python;
- **генетика** — ДНК как код из четырёх букв, генетический код, наследование признаков, генетические маркеры,
  сборка генома.

Главная мысль, которую выносит участник: **ДНК — это тоже код**. С ним работают теми же приёмами, что
и программисты: кодируют, расшифровывают, сравнивают и собирают.

## Формат

| Параметр | Значение |
|---|---|
| Аудитория | школьники 7–11 классов, специальных знаний не требуется: всё нужное есть в памятках на экране |
| Длительность | 20–30 минут (расчёт по блокам ниже) |
| Устройство | компьютер или телефон, ширина экрана от 320 px |
| Вход | имя и фамилия (для рейтинга), без пароля |
| Задания | 7 заданий в 4 блоках, от лёгких к сложным |
| Проверка ответа | на бэкенде, ответ — строка. Каждая попытка сохраняется |
| Подсказки | у каждого задания свои, открываются по одной. Чем сложнее задание, тем их меньше относительно числа решений |

## Блоки и задания

Сложность оценена по критериям документа «crit», расчёт — в [tasks.md](tasks.md).

| Блок | Задание | О чём | `task_type` | Сложность | Время |
|---|---|---|---|---|---|
| **1. Пропуск в лабораторию** | 1. Замок вольера | Перевести номер вольера (45) в двоичный код и открыть электронный замок | `binary` | лёгкое | 2–3 мин |
| **2. Язык ДНК** | 2. Вторая цепь | По одной цепи ДНК восстановить вторую по правилу пар A–T, G–C | `complement` | лёгкое | 2–3 мин |
| | 3. Генетический код | Разбить РНК на тройки-кодоны и по таблице прочитать слово-метку пробирки | `codon` | среднее | 3–4 мин |
| **3. Наследственность** | 4. Решётка Пеннета | Заполнить решётку для двух родителей-носителей и найти вероятность светлого детёныша | `probability` | среднее | 3–4 мин |
| | 5. Кто отец? | По генетическим маркерам найти, какой из четырёх самцов — отец детёныша | `paternity` | среднее+ | 4–5 мин |
| **4. ДНК-паспорт** | 6. Поиск мутаций | Дописать программу на Python, которая сравнивает две последовательности и находит позиции мутаций | `mutation` | сложное | 4–5 мин |

Итого 22–29 минут вместе с брифингами плюс около минуты на вход и итоги — в пределах 20–30 минут.

### Сюжетная линия по блокам

1. **Пропуск в лабораторию.** Терминал заблокирован после сбоя. Электронный замок принимает номер вольера
   манула только в двоичном коде. *Навык:* позиционная система счисления.
2. **Язык ДНК.** В холодильнике лежит пробирка с пробой детёныша, но этикетка повреждена. Участник восстанавливает
   вторую цепь ДНК, затем читает ген-метку пробирки. В метке оказывается слово **TIGER**: пробы перепутаны,
   в пробирке манула лежит проба амурского тигра. Теперь происхождение детёныша нельзя просто взять из базы,
   его нужно доказать. *Навыки:* комплементарность, генетический код.
3. **Наследственность.** У детёныша редкая светлая окраска, хотя оба вероятных родителя тёмные. Участник
   проверяет по решётке Пеннета, что так бывает: у двух родителей-носителей вероятность 25%. Затем по четырём
   маркерам находит отца среди четырёх самцов. *Навыки:* законы Менделя, наследование аллелей, логический вывод.
4. **ДНК-паспорт.** Для паспорта нужно найти мутации в гене окраса и собрать ген из коротких фрагментов
   секвенатора. Один фрагмент — загрязнение из той самой пробы тигра. *Навыки:* циклы и индексы в Python,
   поиск перекрытий.

**Финал:** ДНК-паспорт собран, происхождение подтверждено. Детёныш получает имя **Байт**, а участник —
строчку «происхождение подтвердил: …» в паспорте.

## Завершение квеста

Квест можно закончить в любой момент кнопкой «Завершить смену» (то есть сдаться). Тогда:
- результат фиксируется: все решённые задания и попытки уже на бэкенде, в рейтинг попадают баллы
  на момент завершения;
- участник видит концовку, которая зависит от того, сколько заданий решено;
- на экране итоги (баллы, решено заданий, попыток, время) и призыв **«Найди себя на лидерборде»**;
- локальный прогресс сбрасывается, следующий участник на том же устройстве начинает с ввода имени.

| Решено заданий | Концовка | Смысл |
|---|---|---|
| 0–2 | «Ночная смена окончена» | Смену начали, но до ДНК не дошли. Утром генетики начнут с того, что вы успели |
| 3–4 | «Лаборант» | Вы прочитали ДНК и нашли подмену проб. Без этого паспорт оформили бы с ошибкой |
| 5–6 | «Генетик» | Вы доказали происхождение детёныша. Осталось собрать паспорт, утром это сделает Вера |
| 7 | Финал «Код манула» | Паспорт собран, детёныш получает имя Байт |

Полное прохождение — тоже завершение: показывается финал с теми же итогами и призывом.

## Баллы и рейтинг

- За задание начисляются баллы по уровню: лёгкое — 10, среднее — 15, сложное — 20. Максимум — 105.
- Неверные попытки баллов не снимают, но учитываются в рейтинге: при равных баллах выше тот, у кого меньше попыток,
  потом — кто быстрее (правило бэкенда: `score DESC, solved_tasks DESC, attempts_count ASC, time_seconds ASC`).
- Набор заданий на бэкенде включается и выключается флагом `is_active`. Например, в короткий день
  проведения можно оставить только блоки 1–3.

## Принципы заданий

- Каждое задание учит одной идее. Всё нужное для решения есть в памятке на экране задания.
- Ответ — короткая строка, которую проверяет бэкенд. Правильных ответов во фронтенде нет.
- Задания построены на выборе и сборке из готовых элементов. Ручной ввод есть только там, где он часть навыка
  (расшифровка слова, позиции мутаций). Так удобно и с телефона.
- Сложность растёт по критериям crit: меньше подсказок на одно решение, больше вариантов перебора,
  слабее обратная связь, нужнее знание инструмента.
- Сюжет сквозной: результат каждого задания — улика для следующего.
