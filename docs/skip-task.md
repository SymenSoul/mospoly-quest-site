# Пропуск задания (#25)

Источник: комментарий Матвея Веселова от 21.10.2026 в таблице «Задачи (Квест сайт)» к строке 25: пропуск без возврата, с информацией для следующего блока; возможность завершить смену сохраняется.

Участник подтверждает необратимый пропуск и видит существующий сюжетный итог, где находится информация для продолжения. Кнопка перехода открывает следующий шаг. Выбор пропущенного задания в меню позволяет перечитать итог, но не решить задание или открыть подсказку. `QuestSession.submitAnswer` дополнительно отклоняет отправку для локально пропущенного задания.

`skipped` переживает перезагрузку. Старые снимки сессии version 2 совместимы (по умолчанию пустой список). Решённые и закрытые задания пропустить нельзя. Баллы и решённые задания не меняются; фиктивные верные ответы не отправляются.

Текущий сервер разрешает `completed` лишь после решения всех заданий. Поэтому после любого пропуска финал вызывает существующий API с `gave_up`: рейтинг содержит только реально решённые задания, итоговый экран выбирается по их числу. Серверная статистика пропусков и защита от ручного изменения localStorage требуют отдельного расширения Django API; в данный PR они не входят. Все задания и ветка `dev` сохраняются без изменения правильных ответов.

Проверка: `node --test tests/taskNavigation.test.js`, сборка и интеграционный прогон с mock API. Браузерный барьер не является серверной защитой.
