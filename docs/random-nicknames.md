# Случайные ники — задача №21

На экране входа по умолчанию предлагается ник из 576 сочетаний прилагательного и животного.
«Другой ник» меняет сочетание без немедленного повтора. Можно переключиться на ручной ввод имени и фамилии.
Оба режима работают для квестов `zoo` и `orlov`.

API не меняется: прилагательное передаётся как `first_name`, животное как `last_name`.
Ник виден в сессии и рейтинге. Он не уникален и не используется для авторизации или запрета повторов.
Новых зависимостей нет. Проверка генератора: `node --test tests/nickname.test.js`.
